Luxel was made in Godot 4.7 for a game jam with the theme Trade-off. Marwan Abudaif came up with the game, designed it and its architecture, directed the art and sound, and debugged and tuned it through play-testing. Claude Code, an AI coding assistant, carried out the implementation from his designs.

## WHO DID WHAT

| | |
|---|---|
| Marwan Abudaif | Concept, game design, technical architecture, story, art direction, audio direction, debugging, play-testing and tuning |
| Claude Code (AI) | Implementation: writing the code and assets to Marwan's designs and specifications |

## BUILT WITH

Godot 4.7 and GDScript, on the GL Compatibility renderer so the game runs in a browser. Sound effects from Kenney's audio packs (CC0).
